PROJECT NAME: CampusHub – Campus Event and Club Management System

PROJECT DESCRIPTION:

CampusHub is a web-based Campus Event and Club Management System designed to manage university clubs and campus events efficiently.

The system allows students to explore university clubs, view upcoming events, and register for events. Club organizers can create and manage events, while administrators can manage users, clubs, venues, and event categories.

TECHNOLOGIES:

Traditional Web Application:
- Spring Boot
- Spring Data JPA
- Thymeleaf
- Tailwind CSS
- Spring Security
- H2 Database

Single Page Application:
- Spring Boot
- Spring Data JPA
- React.js
- Tailwind CSS
- OAuth2 Authorization Server
- API Gateway
- H2 Database

DATABASE ENTITIES:

- Club
- Event
- Venue
- Category
- EventReport

RELATIONSHIPS:

- Club and Event: One-to-Many
- Venue and Event: One-to-Many
- Event and Category: Many-to-Many
- Event and EventReport: One-to-One

USER ROLES:

- Administrator
- Club Organizer
- Student

MAIN FEATURES:

- User login and authentication.
- Role-based authorization.
- Club management.
- Event management.
- Venue management.
- Event registration.
- Event category management.
- Event report management.

PROJECT OBJECTIVE:

To develop two versions of a web-based application using traditional web application architecture and single page application architecture, demonstrating the implementation of modern web development technologies and security mechanisms.
